### リリース履歴

******

# v2.0.0

###### 2026/08/29

* `機能` 1つのソースカラーからツールバー、操作、サーフェス、輪郭、エラー用の読みやすい明暗セマンティック色を生成する詳細なHCT配色を追加し、ローカライズ済みMaterial 500の19色とライブプレビュー付きカスタムRGBを提供
* `機能` ランチャーと1ファイル対応の単独プレーヤーを追加し、言語、ナイトモード、テーマカラー、再開、更新、リリース履歴、アプリと開発者情報の専用設定画面を提供
* `機能` 言語、ナイトモード、ソースカラーは公式の読み取り専用設定契約を通じて既定でAutoJs6に従います。ホストが利用できない場合も選択肢は無効表示され、アプリの既定値に戻ります
* `機能` 手動および1日1回の自動更新確認、無視したバージョンの管理、ローカライズ済み内蔵リリース履歴を追加
* `修正` ホスト設定プロバイダーが必要とする保護されたプラグイン情報サービス入口を公開し、AutoJs6への追従を確実にしました
* `改善` 再開位置は最後に開いた動画1件だけを記憶し、別の動画を開くと以前の記録を直ちに破棄し、単独履歴とホスト履歴のどちらにも再生完了位置を保存しません
* `改善` 固定のアプリ・プラグイン表示名を3-Ember Player、ソース名前空間をthreeemberplayerに変更し、更新互換性のため公開済みIDは維持

# v1.4.0

###### 2026/08/28

* `機能` Explorer Action v12 のリクエスト限定・UID 固定 Host Session により同じフォルダーの動画を自然順でキュー化し、前へ / 次へ、順次、シャッフル、1 項目リピート、自動次項再生に対応
* `機能` 同名の .srt / .ass 外部字幕とその言語サフィックス形式を検出し、既定では字幕をオフのまま、ユーザーが明示的に選択した場合のみ読み込み
* `機能` ホスト管理の任意の再開履歴を追加。記録は既定でオフで、AutoJs6 設定から無効化または消去でき、ファイル一覧に視聴済み表示は追加しません
* `修正` ホストが動画と分類した Explorer リクエストでも拡張子が旧 23 項目の許可リストになければ拒否される問題. 信頼済みの `video/*` リクエストを一律に受け入れるよう変更
* `改善` 同階層アクセスを選択ファイルと読み取り可能な直下の兄弟ファイルだけに限定し、再帰探索、書き込み、永続 grant、プラグイン内の平文パス保存を禁止
* `改善` シリアライズするキューを動画 128 件、動画ごとの字幕 8 件、字幕関連付け合計 128 件に制限しつつ、選択項目を必ず保持
* `改善` 互換要件を AutoJs6 6.8.0 build 5276 と Explorer Action v12 に固定。任意拡張に未対応のホストでは安全に単一ファイル再生を維持
* `依存関係` 同梱 Explorer Action API をプロトコル v2 から後方互換の v12 メディアセッション拡張へ更新

# v1.3.1

###### 2026/08/27

* `修正` 検証済みの VFW/FourCC XVID トラックを端末内蔵の MPEG-4 Part 2 デコーダーへ渡す軽量な XVID-in-MKV 互換レイヤーを追加しました。トランスコードや元ファイルの変更は行いません
* `修正` 互換システムデコーダーがない場合やデコードに失敗した場合は音声のみの再生を停止し、専用の説明と別のアプリで開く操作を表示します

# v1.3.0

###### 2026/08/27

* `機能` スリープタイマー: 15, 30, 45, 60 分後または現在の動画終了時に一時停止し, リピートとの競合も処理
* `機能` 画面操作: 0.25× から 4× のピンチズーム, ズーム中のダブルタップリセット, 既存表示モードとの連携
* `機能` シークプレビュー: 目標時刻と任意のメモリ内サムネイルを表示し, 抽出失敗時は通知せず時刻表示だけに切り替え
* `機能` Android 10+ で現在のフレームをストレージ権限なしに MediaStore 経由の別 PNG として保存し, 元の動画は変更しない
* `機能` 低/標準/高のジェスチャー感度と 5/10/30 秒のダブルタップシークを永続設定
* `改善` スリープ期限は経過時間を使い, 時計変更に依存せず再生ページの状態再作成後も復元
* `改善` サムネイル抽出は高速なシーク要求を単一ワーカーで統合し, 古くなった一時 Bitmap をすべて解放

* `機能` トラック選択: 言語とチャンネル情報付きの内蔵音声トラックを切り替え, 既定でオフの内蔵字幕を必要に応じて有効化
* `機能` Android 8.0以降のピクチャー イン ピクチャー: 再生中に離れた際の自動移行, 手動移行, 動画比率への追従, 遠隔再生/一時停止

* `機能` 再生ツール: 現在の動画のリピート, 動画情報パネル, 画面比率に基づく1回限りの方向選択
* `改善` 非対応トラックを明確に表示して選択不可とし, 実際の選択肢がない場合はトラック操作を非表示化
* `改善` 厳密な内部リクエストは情報パネル用に安全な表示名と検証済み宣言サイズだけを保持
* `依存関係` AndroidX Media3 Session 1.10.1を追加

# v1.1.0

###### 2026/08/27

* `機能` ジェスチャー操作: 画面左右半分の縦スワイプで明るさとメディア音量を調節, 横スワイプでシーク, 左右のダブルタップで10秒移動, 中央のダブルタップで再生/一時停止, 長押しで一時的な2倍速
* `機能` 再生速度: 0.25×から3×までの9段階を選択でき, 1×以外ではコントロールバーに現在の速度を強調表示
* `機能` 没入型フルスクリーン: システムバーを隠しディスプレイカットアウトに対応, オーバーレイ表示のタイトルバーとコントロールバーは自動的に隠れ, 画面の向きと画面サイズをワンタップで切り替え
* `機能` 操作ロック: ワンタップで全てのコントロールとジェスチャーを無効化し誤操作を防止
* `機能` 再生位置の記憶: content URIのSHA-256ダイジェストをキーに前回位置からローカルで再開, 視聴完了で自動消去, 最大200件
* `改善` 下部コントロールバーを自前のレイアウトに刷新し, 再生/一時停止, 10秒ジャンプ, ドラッグ可能なシークバーとバッファー進捗表示を提供
* `改善` 再生失敗パネルに再試行アクションを追加し, 別のアプリで開くも維持
* `改善` 画面回転などの構成変更でプレーヤーを再構築せず, より滑らかに切り替え
