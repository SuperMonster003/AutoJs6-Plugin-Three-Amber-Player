# v4.0.0

###### 2026/10/03

* `提示` 3-Amber Player 4.0 使用新应用 ID io.github.supermonster003.autojs6.plugin.three.amber.player. Android 将其作为独立应用安装, 旧播放器设置不会自动迁移, 旧应用可以保留并存
* `新增` 设置页提供自适应亮色, 自适应暗色, 自适应自动 (默认)与透明背景四种启动器图标. 自动配色与透明效果取决于启动器, 部分系统可能缓存图标或添加背景. 切换后部分主屏幕快捷方式可能需要重新添加
* `新增` 统一语言, 夜间模式, 主题色与启动器图标设置, 选择后须确认保存, 支持 16 种预设色与 HEX/RGB 局部预览. 应用外观默认跟随 AutoJs6, 宿主不可用时安全回退
* `修复` 校正 Amber 图案视觉偏左, 对启动器及透明图标应用光学居中, 并将偏移纳入所有安全区校验
* `优化` 采用中性灰阶底色与清晰可读的主题色 Material 3 控件和对话框, 统一间距, 线性图标与分割线. 启动器图标默认改为自动, 升级保留明确选择并修复重复入口
* `优化` 启动器与插件中心图标按统一视觉尺寸标准调整, 插件中心采用透明背景和黑白或中性灰阶图案

# v2.1.0

###### 2026/08/31

* `新增` 字幕样式设置, 支持字号, 前景色, 背景及底部边距, 可实时预览并应用于播放页及画中画

* `优化` 字幕解码, UTF-8 转换与时间平移全部在内存完成, 不创建临时文件, 不申请存储权限, 也不持久保留字幕授权
* `优化` 切换视频时字幕偏移自动归零; A-B 循环激活期间优先执行, 随后显式选择播放模式或播完停止定时会将其清除

# v1.4.0

###### 2026/08/28

* `新增` 同目录连播: 打开一个视频自动生成同文件夹播放队列 (按自然文件名排序), 支持上一个/下一个, 顺序, 随机, 单项循环与播完自动接续
* `新增` 外挂字幕: 自动发现与视频同名的 .srt / .ass 字幕文件及其语言后缀变体; 字幕默认关闭, 在字幕菜单中选择后加载

* `优化` 同目录访问严格限定为选中文件及其可读的直接同级文件, 不允许递归子目录, 写入或持久授权, 插件也不保存明文路径
* `优化` 播放队列上限为 128 个视频, 每个视频最多关联 8 个外挂字幕, 用户选中的视频始终保留在队列中
* `优化` 兼容基线固定为 AutoJs6 6.8.0 (build 5276); 旧版宿主自动回退为单文件播放, 基础功能不受影响
