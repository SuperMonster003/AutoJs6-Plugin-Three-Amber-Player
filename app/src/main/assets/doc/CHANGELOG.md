# v3.1.0

###### 2026/09/13

* `新增` 本地播放列表: 支持 M3U/M3U8, PLS, XSPF, WPL, ASX/WAX/WVX, MPCPL, DPL; 保留顺序, 标题和重复项. 宿主入口读取同目录文件; 独立入口可选择列表文件夹以读取相对路径. 一次打开一个列表, 最多 128 项; 不支持网络地址, HLS 与嵌套列表
* `修复` 插件版本日期固定使用英文, 不随构建机器的语言变化
* `优化` 统一多语言资源, 明确插件激活契约并校验发布产物

# v3.0.0

###### 2026/09/12

* `新增` 完成播放页可访问性审计: 控件具备名称与动态状态, TalkBack 触摸探索时不自动隐藏, 每种手势都有按钮或菜单等价入口, 焦点顺序确定, 并通过 200% 字体与显示缩放验证
* `新增` 支持键盘与遥控器: 清晰焦点环, DPAD 导航, 空格/回车播放暂停, 左右键按已配置的 5/10/30 秒步长跳转, 媒体键交由 MediaSession 处理
* `新增` 新增默认关闭的可选后台听音: 授予通知权限后, 画中画不可用时可将当前播放无缝移交给媒体播放前台服务并通过通知控制
* `优化` 画中画始终优先于后台听音; 关闭设置, 播放完成, 发生错误或主动退出播放都会停止服务, 点击通知则以相同播放器和连续进度返回播放页
* `优化` 耳机行为遵循 Media3: 单击切换播放暂停, 外接设备双击在队列存在下一项时前进, 显式 Previous 媒体命令返回上一项; 不强加非标准三击计时
* `优化` 统一 README 版式与 Gradle 平台版本管理方式
* `优化` 精简插件描述并规范多语言资源中的标点符号
* `优化` 将外部查看入口统一命名为 External Viewer
* `优化` 插件更新对话框的发行历史按钮改为打开内置发行历史页面
* `优化` 构建阶段阻止意外引入原生依赖, 并输出 JSON 校验报告

# v2.3.0

###### 2026/08/31

* `新增` 视频信息现在可标注 HDR10,HLG 或 SDR,并在可得时显示色彩空间,范围与位深;支持一键复制全部字段,显示设备未报告支持片源 HDR 格式时会给出一次性提示
* `新增` 新增默认关闭的`截图包含字幕`设置,可将当前可见字幕绘制到截图;保存 PNG 后可直接通过`分享`发送到其他应用
* `新增` 新增仅当前会话生效的画面镜像,支持左右,上下或双轴翻转,并与双指缩放及屏幕旋转保持一致组合
* `新增` 新增仅当前会话生效的 +3 dB 至 +15 dB 音量增强,默认关闭,首次启用前提示失真与听力风险,设备不支持时自动退回关闭
* `优化` 截图继续作为独立 PNG 通过 MediaStore 保存,无需存储权限;分享时只向目标应用授予所选图片的只读访问
* `优化` 评估后采用 LoudnessEnhancer:它能在不修改媒体文件的前提下提供有上限的播放增益;设备效果创建失败时会立即释放并安全回退

# v2.2.0

###### 2026/08/31

* `新增` 新增 Host Session 播放队列面板:展示文件名,已知时长或占位,高亮当前项,点按跳转,并实时联动顺序,随机与单项循环
* `新增` 新增只读文件管理器动作`播放所选`:按宿主选择顺序播放同一父目录内 1 至 128 个受支持视频,且不发现同级文件
* `新增` 队列自动连播前保留当前末帧并显示可取消的 3 秒下一项提示,控制锁定状态不会被解除
* `新增` 新增默认关闭的`记住播放模式`设置,可跨播放会话保留顺序,随机或单项循环
* `优化` 每个所选目标都会分别核对 content URI,ClipData 位置,MIME,元数据,大小与父目录;ID 或 URI 重复时整组拒绝
* `优化` 多选仅通过有界 Host Session 路由读取宿主明确授权的目标,不扫描同级视频或字幕

# v2.1.0

###### 2026/08/31

* `新增` 新增字幕样式设置: 字号可选 75%-150%, 前景色, 不透明/半透明/无背景及 0%/4%/8% 底部边距均可实时预览, 并持久应用于播放页与画中画
* `新增` 新增外挂字幕编码探测: BOM 优先, 随后识别 GBK, Big5, Shift_JIS, EUC-KR, Windows-1251 与 Windows-1256, 无法可靠识别时明确提示可能乱码
* `新增` 字幕菜单新增从文件加载: 通过系统文档选择器临时读取单个 .srt 或 .ass 字幕, 超过 4 MiB 或扩展名不符时拒绝加载
* `新增` 所选外挂字幕可在 −600.0 至 +600.0 秒间按 0.1 秒步长调整, 屏幕提示即时显示当前偏移
* `新增` 暂停时可逐帧后退或前进 (长按连续执行), 并可设置边界自动归一化的 A-B 区间循环
* `优化` 字幕解码, UTF-8 转换与时间平移全部在内存完成, 不创建临时文件, 不申请存储权限, 也不持久保留字幕授权
* `优化` 切换视频时字幕偏移自动归零; A-B 循环激活期间优先执行, 随后显式选择播放模式或播完停止定时会将其清除

# v2.0.0

* `新增` 全新主题系统: 由一个主题色自动生成亮色与暗色两套界面配色, 默认跟随 AutoJs6 主题, 也可从 19 个预置色中挑选或自定义 RGB 颜色并实时预览
* `新增` 插件升级为独立应用: 新增桌面启动入口, 可通过系统文件选择器直接打开视频播放
* `新增` 新增设置页面: 集中管理语言, 夜间模式, 主题色, 续播, 更新与发行历史; 语言, 夜间模式与主题色默认跟随 AutoJs6, 宿主不可用时自动禁用相应选项并回退为应用默认值
* `新增` 新增检查更新: 支持手动检查与每日自动检查官方 GitHub 发行版, 可忽略指定版本, 并内置多语言发行历史页面

# v1.4.0

###### 2026/08/28

* `新增` 同目录连播: 打开一个视频自动生成同文件夹播放队列 (按自然文件名排序), 支持上一个/下一个, 顺序, 随机, 单项循环与播完自动接续
* `新增` 外挂字幕: 自动发现与视频同名的 .srt / .ass 字幕文件及其语言后缀变体; 字幕默认关闭, 在字幕菜单中选择后加载
* `新增` 可选的宿主续播历史: 默认不记录, 可在 AutoJs6 设置中开启, 关闭或清除; 文件列表不会显示已看标记
* `修复` 修复部分被宿主识别为视频的文件因扩展名不在旧版白名单而拒绝播放的问题; 现在统一接受宿主可信的 video/* 请求
* `优化` 同目录访问严格限定为选中文件及其可读的直接同级文件, 不允许递归子目录, 写入或持久授权, 插件也不保存明文路径
* `优化` 播放队列上限为 128 个视频, 每个视频最多关联 8 个外挂字幕, 用户选中的视频始终保留在队列中
* `优化` 兼容基线固定为 AutoJs6 6.8.0 (build 5276); 旧版宿主自动回退为单文件播放, 基础功能不受影响
* `依赖` 内置 Explorer Action 接口从协议 v2 升级到向后兼容的 v12

# v1.0.0

###### 2026/08/02

* `新增` 首个版本: 作为 AutoJs6 文件管理器插件发布, 在文件管理器中点击视频文件即可直接播放
* `新增` 覆盖 23 种常见视频扩展名 (MP4, MKV, AVI, MOV, FLV, WEBM 等), 以只读方式承接文件管理器的视频打开动作
* `新增` 基于 AndroidX Media3 ExoPlayer 播放: 自动播放, 标准控件, 音频焦点管理, 拔出耳机自动暂停, 播放中保持屏幕常亮

* `新增` 独立的系统打开方式入口: 其他应用可通过只读 content URI 调用本播放器观看视频
* `新增` 播放失败时可安全转交其他应用打开, 候选列表自动排除本插件
* `新增` 内置 10 种语言: 简体中文, 繁体中文 (香港/台湾), 英语, 法语, 西班牙语, 日语, 韩语, 俄语与阿拉伯语
