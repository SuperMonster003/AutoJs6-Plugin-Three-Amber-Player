# 3-Ember Player

3-Ember Player는 파일 관리자에 읽기 전용 기본 동영상 작업을 추가합니다. AndroidX Media3 ExoPlayer와 PlayerView를 사용하고 자동으로 재생을 시작하며 오디오 포커스와 noisy 출력 변경을 처리하고 재생 위치와 상태를 복원합니다.

전체 연동에는 AutoJs6 6.8.0 build 5276 이상과 Explorer Action v12가 필요하며 이후 플러그인 기능에서도 이 기준을 높이지 않습니다. 설치되고 활성화되고 신뢰되며 호환되면 호스트가 동영상으로 인식한 모든 파일이 이 플레이어에서 열립니다. 선택적 세션 기능이 없는 호스트는 선택 파일만 재생합니다. 플러그인이 없거나 비활성화되거나 승인되지 않았거나 사용할 수 없거나 호환되지 않거나 실행할 수 없으면 호환 호스트가 복구 안내를 표시하고 사용자가 다른 앱으로 열기를 명시적으로 선택한 경우에만 Android 앱 후보를 표시합니다. 오디오와 이미지 보기는 독립 기능입니다.

재생 조작:

- 화면 왼쪽 또는 오른쪽 절반을 세로로 스와이프하면 각각 밝기 또는 미디어 볼륨을 조절합니다.
- 가로 스와이프로 탐색하고 좌우 1/3 더블 탭으로 설정한 5, 10, 30초 이동, 중앙 더블 탭으로 재생/일시정지, 길게 눌러 일시적인 2배속을 사용합니다.
- 하단 바는 재생/일시정지, 10초 이동, 드래그 가능한 진행 바, 0.25×–3× 재생 속도, 화면 비율, 화면 방향, 오터치 방지 잠금을 제공합니다.
- 탐색기에서 동영상 하나를 열면 읽을 수 있는 직접 형제 동영상을 자연 정렬한 제한된 재생목록으로 만들 수 있습니다. 선택 동영상에서 시작하며 이전 / 다음, 순차, 셔플, 한 항목 반복을 제공합니다.
- 호환 호스트는 같은 상위 폴더의 동영상 1~128개를 선택 순서대로 재생하는 읽기 전용 ‘선택 항목 재생’도 표시하며 형제 파일을 검색하지 않습니다. 호스트 대기열은 현재 항목/길이 패널과 탭 이동을 제공하고 마지막 프레임에서 취소 가능한 3초 안내를 거치며 선택적으로 재생 모드를 기억합니다.
- 이어서 재생 기록은 가장 최근에 연 미완료 동영상 하나만 SHA-256 식별 다이제스트와 시간 값으로 보관합니다. 다른 동영상을 열면 즉시 삭제되고 완료된 재생은 저장하지 않습니다.
- 상단 바에서 내장 오디오와 텍스트 트랙을 선택합니다. 같은 폴더의 이름이 일치하는 .srt / .ass 외부 자막과 언어 접미사를 찾습니다. 모든 자막은 기본으로 꺼져 있고 명시적으로 선택한 뒤에만 로드됩니다.
- 상단 바는 현재 동영상 반복, 동영상 정보, 가로 동영상 자동 방향 제안, Android 8.0+ PIP 모드의 재생/일시정지 기능도 제공합니다.
- MediaSession은 헤드셋, Bluetooth 및 시스템 재생 컨트롤을 지원하며 미디어 알림에 현재 제목과 진행률을 표시합니다.
- 취침 타이머는 15, 30, 45, 60분 후 또는 동영상 끝에서 재생을 일시정지합니다. 제스처 설정에서 감도와 더블 탭 탐색 간격을 선택할 수 있습니다.
- 화면을 핀치하면 0.25×–4×로 확대/축소되고 확대 중 더블 탭하면 초기화됩니다. 진행 바를 드래그하면 목표 시간이 표시되며 컨테이너가 지원하면 미리보기도 표시됩니다.
- Android 10 이상에서는 현재 프레임 저장으로 PNG를 Pictures/3-Ember Player에 저장합니다. 이전 버전에서는 항목이 숨겨집니다.
- 하나의 HCT 원본 색상으로 읽기 쉬운 밝은색·어두운색 의미 역할을 만들고 기본적으로 AutoJs6를 따르며 현지화된 Material 500 색상 19개와 실시간 미리보기 사용자 RGB를 제공합니다. 독립 런처와 호스트를 따르는 언어·야간 모드·색상, 동영상 하나 이어서 재생, 수동·자동 업데이트 확인, 무시한 버전, 릴리스 기록, 앱 및 개발자 정보 설정을 제공합니다.

자막 및 정밀 재생 도구:

- 자막 설정에서 75%~150% 글자 크기, 네 가지 전경색, 불투명·반투명·배경 없음, 0%·4%·8% 아래쪽 여백을 실시간으로 미리 볼 수 있습니다. 선택한 값은 PIP 모드에도 적용됩니다.
- 자막 메뉴에서 최대 4 MiB의 .srt 또는 .ass 파일 하나를 임시로 불러오고, 메모리에서 BOM/GBK/Big5/Shift_JIS/EUC-KR/Windows-1251/Windows-1256을 감지하며, 외부 자막을 0.1초 단위로 ±600.0초 조정할 수 있습니다. 영구 접근 권한은 보관하지 않습니다.
- 일시 중지하면 이전/다음 프레임 버튼(길게 눌러 반복)과 A–B 반복 구간 버튼이 표시됩니다. 활성 A–B 반복은 재생 목록의 다음 항목으로 넘어가지 않게 하며, 이후 반복 모드나 동영상 종료 타이머를 선택하면 해제됩니다.

화면, 접근성 및 백그라운드 재생:

- 정보 패널은 HDR10, HLG 또는 SDR과 확인 가능한 색상 정보를 표시합니다. 스크린샷에 자막을 포함해 공유할 수 있으며, 반전과 경고 확인 후 +3~+15 dB 증폭은 현재 세션에만 적용됩니다.
- TalkBack에서는 이름이 지정된 컨트롤이 계속 표시되고 모든 제스처에 버튼 또는 메뉴 대체 경로가 있습니다. 200% 글꼴/화면 배율과 보이는 키보드/DPAD 포커스, Space/Enter, 설정 단위 좌우 탐색, MediaSession 키를 지원합니다.
- 헤드셋 여러 번 누르기는 Media3가 처리합니다. 한 번 누르면 재생/일시정지, 외부 기기 두 번 누르기는 다음 대기열 항목이 있을 때 이동, 명시적 Previous 명령은 이전 항목으로 이동합니다. 비표준 세 번 누르기 인식기를 추가하지 않습니다.
- 백그라운드 오디오는 기본값이 꺼짐이며 알림 권한이 필요합니다. PIP를 사용할 수 없을 때만 기존 플레이어를 알림 제어가 있는 비공개 미디어 재생 포그라운드 서비스로 넘깁니다. PIP가 우선하며 설정 해제, 완료, 오류 또는 명시적 종료 시 서비스를 중지합니다. FOREGROUND_SERVICE와 FOREGROUND_SERVICE_MEDIA_PLAYBACK은 이 명시적으로 활성화된 수명 주기에만 사용하고 URI 접근은 임시로 유지합니다.

탐색기 확장자:

- MP4, MPEG4, MPG4, AVI, MKV, MOV, FLV, WEBM, M4V, 3GP, MPEG, 3G2, 3GP2, 3GPP, F4V, M2T, M2TS, MTS, TS, MPG, MPE, VOB, QT.

안전 및 개인정보 제한:

- 파일 관리자 실행에는 signature 수준의 플러그인 권한이 필요합니다.
- 플러그인은 임시 읽기 전용 접근이 있는 content URI를 허용하며 원본에 쓰지 않습니다.
- 요청 범위 Host Session은 호스트가 플러그인 UID에 고정하며 선택 파일의 직접 상위 폴더를 비재귀적으로 나열하고 선택 파일 또는 읽을 수 있는 직접 형제 파일을 여는 것만 허용합니다. 플러그인은 파일 시스템 경로를 받지 않습니다.
- 쓰기 및 영구 grant는 거부됩니다. prefix 접근은 플레이어로 전달되지 않습니다.
- 별도의 ACTION_VIEW 진입점은 읽기 전용 동영상 content URI만 허용하고 수신한 extras와 ClipData를 폐기합니다.
- 재생에 실패하면 다른 앱으로 열기 작업이 읽기 전용 Intent를 다시 만들고 이 플러그인을 제외합니다.
- 검증된 XVID-in-MKV 트랙은 트랜스코딩 없이 기기의 MPEG-4 Part 2 디코더를 사용합니다. 디코더를 사용할 수 없거나 실패하면 재생을 중지하고 다른 앱으로 열기를 제공합니다.
- 실제 디코딩은 Media3 extractor와 기기에서 사용할 수 있는 코덱에 따라 달라집니다.
- 이어서 재생 기록은 가장 최근에 연 미완료 동영상 하나만 SHA-256 식별 다이제스트와 시간 값으로 보관합니다. 다른 동영상을 열면 즉시 삭제되고 완료된 재생은 저장하지 않습니다.
- 정보 패널은 재생 세션 메타데이터, 안전한 표시 이름과 선언된 크기만 사용하며 원본 동영상을 검색하거나 수정하지 않습니다.
- 요청한 스크린샷은 MediaStore를 통해 별도 PNG로 생성되며 원본 동영상에 쓰지 않습니다. 탐색 미리보기는 메모리에만 있고 추출할 수 없으면 조용히 생략됩니다.
