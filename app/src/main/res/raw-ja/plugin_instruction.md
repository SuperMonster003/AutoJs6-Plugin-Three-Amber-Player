# 3-Ember Player

3-Ember Playerはファイルマネージャーに読み取り専用のプライマリ動画アクションを追加します. AndroidX Media3 ExoPlayerとPlayerViewを使用し, 自動的に再生を開始し, オーディオフォーカスとnoisy出力変化を処理し, 再生位置と再生状態を復元します.

完全な連携には AutoJs6 6.8.0 build 5276 以降と Explorer Action v12 が必要で, 今後のプラグイン機能でもこの基準は引き上げません. インストール済み, 有効, 信頼済み, 互換であればホストが動画として認識したすべてのファイルをこのプレーヤーで開きます. 任意のセッション機能がないホストでは選択ファイルだけを再生します. プラグインが未インストール, 無効, 未承認, 利用不可, 非互換, または起動できない場合, 対応ホストは復旧案内を表示し, ユーザーが明示的に「他のアプリで開く」を選択した場合にのみ Android のアプリ候補を表示します. 音声再生と画像表示は独立した機能です.

再生操作:

- 画面の左半分または右半分を縦にスワイプすると, それぞれ明るさまたはメディア音量を調節できます.
- 横スワイプでシークし, 左右 1/3 のダブルタップで設定した 5, 10, 30 秒を移動, 中央のダブルタップで再生/一時停止, 長押しで一時的な 2 倍速になります.
- 下部バーには再生/一時停止, 10 秒ジャンプ, ドラッグ可能なシークバー, 0.25× から 3× の再生速度, 画面サイズ, 画面の向き, 誤操作防止のロックがあります.
- Explorerから1本を開くと, 読み取り可能な直接同階層の動画を自然順の上限付きキューにできます. 選択動画から開始し, 前へ / 次へ, 順次, シャッフル, 1項目リピートを利用できます.
- 再開履歴には最後に開いた未完了動画1件だけをSHA-256識別ダイジェストと時間値として保存します。別の動画を開くと直ちに消去され、再生完了位置は保存しません。
- 上部バーで内蔵音声とテキストトラックを選択できます. 同じフォルダーの一致する .srt / .ass 外部字幕と言語サフィックスを検出します. 字幕はすべて既定オフで, 明示的な選択後だけ読み込みます.
- 上部バーには現在の動画のリピート, 動画情報, 横長動画の自動方向設定, Android 8.0以降の再生/一時停止対応ピクチャー イン ピクチャーもあります.
- MediaSessionによりヘッドセット, Bluetooth, システムから操作でき, メディア通知に現在のタイトルと進行状況が表示されます.
- スリープタイマーは 15, 30, 45, 60 分後または動画終了時に再生を一時停止します. ジェスチャー設定で感度とダブルタップのシーク幅を選べます.
- 画面をピンチすると 0.25× から 4× までズームし, ズーム中のダブルタップでリセットできます. シークバーのドラッグ中は目標時刻が表示され, コンテナが対応する場合はサムネイルも表示されます.
- Android 10 以降では「現在のフレームを保存」で PNG を Pictures/3-Ember Player に保存できます. 以前のバージョンでは項目が非表示になります.
- 1つのHCTソースカラーから読みやすい明暗セマンティック色を生成し、既定でAutoJs6に従い、ローカライズ済みMaterial 500の19色とライブプレビュー付きカスタムRGBを提供します。 単独ランチャーに加え、ホストに従う言語・ナイトモード・色、動画1件の再開、手動・自動更新確認、無視したバージョン、リリース履歴、アプリと開発者情報の設定を提供します。

Explorer拡張子:

- MP4, MPEG4, MPG4, AVI, MKV, MOV, FLV, WEBM, M4V, 3GP, MPEG, 3G2, 3GP2, 3GPP, F4V, M2T, M2TS, MTS, TS, MPG, MPE, VOB, QT.

安全性とプライバシーの制限:

- ファイルマネージャーからの実行にはsignatureレベルのプラグイン権限が必要です.
- プラグインは一時的な読み取り専用アクセスを持つcontent URIだけを受け入れ, ソースへ書き込みません.
- リクエスト単位のHost SessionはホストによってプラグインUIDに固定され, 選択ファイルの直接の親を非再帰で列挙し, 選択ファイルまたは読み取り可能な直接同階層ファイルを開くことだけを許可します. プラグインはファイルシステムパスを受け取りません.
- 書き込みgrantと永続grantは拒否されます. prefixアクセスはプレーヤーへ転送されません.
- 独立したACTION_VIEWエントリは読み取り専用の動画content URIだけを受け入れ, 受信したextrasとClipDataを破棄します.
- 再生に失敗した場合, 別のアプリで開く操作は読み取り専用Intentを再構築してこのプラグインを除外します.
- 検証済みのXVID-in-MKVトラックは, トランスコードせずに端末のMPEG-4 Part 2デコーダーを使用します. デコーダーが利用できないか失敗した場合は再生を停止し, 別のアプリで開く操作を表示します.
- 実際のデコード可否はMedia3 extractorと端末で利用可能なコーデックに依存します.
- 再開履歴には最後に開いた未完了動画1件だけをSHA-256識別ダイジェストと時間値として保存します。別の動画を開くと直ちに消去され、再生完了位置は保存しません。
- 情報パネルは再生セッションのメタデータ, 安全な表示名, 申告サイズだけを使い, 元の動画を走査または変更しません.
- スクリーンショットは要求時のみ MediaStore で別の PNG として作成され, 元の動画へ書き込みません. サムネイルはメモリ内だけに保持され, 抽出できない場合は通知せず省略されます.
