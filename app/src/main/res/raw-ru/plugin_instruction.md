# Видеоплеер

Video Player добавляет в Проводник AutoJs6 основное действие для видео только для чтения. Он использует AndroidX Media3 ExoPlayer и PlayerView, автоматически начинает воспроизведение, управляет фокусировкой звука и переходом к noisy-аудиовыходу, а также восстанавливает позицию и состояние воспроизведения.

Для плагина требуется AutoJs6 build 5269+. Когда он установлен, включен, признан доверенным и совместим, подходящие видеофайлы открываются в этом проигрывателе. Если плагин отсутствует или недоступен, AutoJs6 возвращается к маршруту Android ACTION_VIEW. Воспроизведение аудио и просмотр изображений остаются отдельными возможностями плагинов.

Расширения Проводника:

- MP4, MPEG4, MPG4, AVI, MKV, MOV, FLV, WEBM, M4V, 3GP, MPEG, 3G2, 3GP2, 3GPP, F4V, M2T, M2TS, MTS, TS, MPG, MPE, VOB, QT.

Ограничения безопасности и конфиденциальности:

- Для запуска из Проводника требуется разрешение плагина AutoJs6 уровня signature.
- Плагин принимает content URI с временным доступом только для чтения и никогда не изменяет источник.
- Доступ на запись и постоянный доступ отклоняются. Доступ prefix никогда не передается проигрывателю.
- Отдельная точка входа ACTION_VIEW принимает только content URI видео с доступом только для чтения и отбрасывает входящие extras и ClipData.
- При ошибке воспроизведения действие Открыть в другом приложении заново создает Intent только для чтения и исключает этот плагин.
- Фактическое декодирование зависит от экстракторов Media3 и доступных на устройстве кодеков.
