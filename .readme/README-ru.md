### Введение

******

3-Amber Player - это плагин воспроизведения видео для файлового менеджера AutoJs6 и одновременно самостоятельный локальный видеоплеер. Нажмите на видеофайл в файловом менеджере, и он сразу начнёт воспроизводиться во весь экран; жесты, скорость воспроизведения, внешние субтитры, непрерывное воспроизведение папки и картинка в картинке покрывают основные возможности популярных плееров. Воспроизведение построено на AndroidX Media3 ExoPlayer.

3-Amber Player 4.0 использует новый ID io.github.supermonster003.autojs6.plugin.three.amber.player. Android устанавливает его отдельно; прежние настройки не переносятся автоматически. Старое приложение можно сохранить

Плагин придерживается модели безопасности только для чтения: видео попадает в плеер по временным разрешениям только на чтение, разрешение на доступ к хранилищу не запрашивается вовсе, а исходные файлы никогда не изменяются и не перемещаются; сеть используется исключительно для проверки обновлений плагина.

### Основные возможности

******

- Локальные плейлисты: M3U/M3U8, PLS, XSPF, WPL, ASX/WAX/WVX, MPCPL, DPL сохраняют порядок, названия и повторы. AutoJs6 читает файлы той же папки; отдельный плеер запрашивает папку для относительных путей. Один список за раз, до 128 записей. Сетевые URL, HLS и вложенные списки не поддерживаются.
- Нажмите и смотрите: коснитесь видеофайла в файловом менеджере AutoJs6, и он сразу откроется в иммерсивном полноэкранном режиме, никакой настройки не требуется.
- Удобные жесты: свайп по левой половине экрана регулирует яркость, по правой - громкость, горизонтальный свайп перематывает, двойное касание по краям выполняет переход, двойное касание по центру ставит на паузу и снимает с неё, долгое нажатие временно включает скорость 2×, а одно касание блокирует всё управление от случайных нажатий.
- Скорость и изображение: 9 скоростей воспроизведения от 0,25× до 3×, масштабирование щипком (от 0,25× до 4×), режимы вписать/заполнить/обрезать и смена ориентации экрана одним касанием с автоматической подсказкой по соотношению сторон.
- Воспроизведение папки: открытие видео строит очередь в естественном порядке; панель подсвечивает текущий элемент, показывает известную длительность, позволяет переходить касанием и менять режим, а перед автопереходом выводит отменяемую трёхсекундную подсказку.
- Очередь в порядке выбора хоста: действие только для чтения «Воспроизвести выбранное» ставит 1-128 видео из одной папки точно в выбранном порядке без поиска соседних файлов; отдельная настройка может запоминать режим между сеансами.
- Внешние и встроенные субтитры: автоматически находите подходящие .srt / .ass или загружайте один файл вручную, распознавайте распространённые старые кодировки, настраивайте стиль и сдвиг внешних субтитров на ±600 секунд, переключайте встроенные дорожки; субтитры выключены до явного включения.
- Точная навигация: на паузе переходите по кадрам назад и вперёд с повтором по долгому нажатию и задавайте или очищайте интервал A-B для детального просмотра.
- Продолжение просмотра: позиция последнего недосмотренного видео запоминается и восстанавливается при повторном открытии; досмотренные видео удаляются сразу и не оставляют следов просмотра.
- Картинка в картинке и системная интеграция: на Android 8.0+ при выходе из приложения во время воспроизведения автоматически включается маленькое окно, поддерживается управление с гарнитуры и по Bluetooth, а медиауведомление показывает название и прогресс.
- Таймер сна: автоматическая пауза через 15/30/45/60 минут или после окончания текущего видео.
- Предпросмотр перемотки: при перетаскивании полосы прогресса появляется пузырёк с целевым временем и, когда это возможно, миниатюра кадра.
- Снимок кадра: на Android 10+ текущий кадр сохраняется в системную галерею как PNG одним касанием, без разрешения на доступ к хранилищу и без изменения исходного видео.
- Подстраховка для сложных форматов: встроенный лёгкий слой совместимости XVID-in-MKV; если устройство не может декодировать видео, показывается понятное сообщение, и воспроизведение можно передать другому плееру.
- Единые настройки языка, ночного режима, цвета темы и значка запуска с подтверждением, 16 готовыми цветами и предпросмотром HEX/RGB. По умолчанию оформление следует AutoJs6 и безопасно использует резервные настройки при недоступности хоста.
- Работает автономно: у плагина есть значок на главном экране и страница настроек, видео открываются через системный выбор файлов, а в системном меню "Открыть с помощью" его можно выбрать как видеоплеер.
- Экран и вывод: просматривайте HDR10/HLG/SDR и доступные данные о цвете, копируйте всю панель, при желании включайте субтитры в снимок для отправки, отражайте изображение в рамках сеанса или после предупреждения усиливайте громкость до +15 дБ.
- Доступно без жестов: TalkBack сохраняет подписанные элементы управления, у каждого жеста есть кнопка или пункт меню, интерфейс выдерживает масштаб текста и экрана 200 %, поддерживаются фокус клавиатуры/DPAD, Пробел/Ввод, перемотка и клавиши MediaSession.
- Необязательный фоновый звук: по умолчанию выключен и доступен только с разрешением уведомлений; если PiP недоступен, существующий плеер передаётся foreground-сервису воспроизведения с управлением из уведомления и останавливается после завершения или выключения настройки. PiP всегда имеет приоритет.
- Только чтение по замыслу: без разрешения на доступ к хранилищу, в исходные видео никогда ничего не записывается; сеть нужна только для проверки обновлений.
- Выбор значка запуска в настройках: адаптивный светлый, адаптивный тёмный, адаптивный автоматический (по умолчанию) или прозрачный фон. Автоматические цвета и прозрачность зависят от лаунчера: он может кешировать значки или добавлять фон. После смены некоторые ярлыки на главном экране может потребоваться добавить заново.

### Установка и использование

******

Перед началом убедитесь, что окружение отвечает следующим требованиям:

```text
host app: AutoJs6 (org.autojs.autojs6)
minimum host build: 5276 (AutoJs6 6.8.0+)
minimum android: 7.0 (API 24)
plugin package: io.github.supermonster003.autojs6.plugin.three.amber.player
```

От установки до первого видео всего 4 шага:

1. Скачайте и установите APK плагина. На главном экране появится значок 3-Amber Player, а возможностями плагина управляет AutoJs6.
2. Откройте AutoJs6, зайдите в `Центр плагинов`, найдите `3-Amber Player` и включите его.
3. Найдите любой видеофайл (например `movie.mp4`) в файловом менеджере AutoJs6.
4. Нажмите на файл, и видео сразу начнёт воспроизводиться во весь экран.

Использование без хоста: откройте 3-Amber Player с главного экрана, нажмите `Открыть видео` и выберите видео через системный выбор файлов; запросы на просмотр видео из других приложений этот плеер тоже может принимать. Требование к версии хоста выше касается только входа через файловый менеджер; на автономное воспроизведение оно не влияет.

Шпаргалка по жестам плеера:

- Одиночное касание: показать или скрыть панель управления.
- Двойное касание по центру: воспроизведение/пауза; двойное касание слева/справа: назад/вперёд на 10 секунд (в настройках можно выбрать 5/10/30 секунд).
- Вертикальный свайп по левой половине: регулировка яркости; по правой половине: регулировка громкости.
- Горизонтальный свайп: предпросмотр позиции перемотки, отпустите, чтобы применить.
- Долгое нажатие: временная скорость 2×, отпустите, чтобы вернуть прежнюю.
- Щипок двумя пальцами: масштабирование изображения (от 0,25× до 4×); двойное касание при изменённом масштабе сбрасывает его.
- Кнопка блокировки: отключает все жесты и элементы управления от случайных нажатий; после блокировки коснитесь экрана, чтобы появилась кнопка разблокировки.

### Поддерживаемые форматы

******

Действие воспроизведения в файловом менеджере срабатывает ровно на следующие 23 расширения:

```text
MP4, MPEG4, MPG4, AVI, MKV, MOV, FLV, WEBM, M4V, 3GP, MPEG, 3G2, 3GP2, 3GPP, F4V, M2T, M2TS, MTS, TS, MPG, MPE, VOB, QT
```

Список выше - это точный список разрешённых расширений, сохранённый для старых версий хоста; в новых версиях любой файл, распознанный как видео, передаётся плагину через `video/*`. Попадание в список не гарантирует декодирование на каждом устройстве: реальная воспроизводимость зависит от Media3 и платформенных декодеров. Автономный вход и вызовы из других приложений также принимаются по MIME-типу `video/*`.

### Частые вопросы

******

**Нажатие на видеофайл не открывает этот плеер?**

Проверьте по порядку: код версии AutoJs6 не ниже 5276 (то есть версия 6.8.0 и выше); плагин включён в `Центре плагинов`; файл распознаётся хостом как видео. Если хотя бы одно из трёх условий не выполнено, нажатие не будет обработано этим плагином.

**Что происходит, когда плагин не установлен или отключён?**

Совместимый хост показывает подсказку по восстановлению с предложением установить или включить плагин; системное меню выбора приложения появляется только после того, как пользователь сам выберет `Открыть в другом приложении`, и тогда видео передаётся другим плеерам на устройстве.

**Звук идёт, а экран чёрный, или воспроизведение вообще не удаётся?**

Сможет ли видео декодироваться, зависит от платформы устройства и Media3; совпадение расширения из списка не гарантирует воспроизведение. Для распространённого устаревшего формата XVID-in-MKV встроенный слой совместимости передаёт дорожку системному декодеру MPEG-4 Part 2; если декодирование всё равно не удаётся, показывается понятное сообщение, а `Открыть в другом приложении` передаёт видео другому плееру.

**Как непрерывно воспроизвести все видео в папке?**

Если хост соответствует требованию к версии сборки, открытие любого видео из файлового менеджера автоматически строит очередь из той же папки: естественный порядок имён файлов, старт с текущего видео, автопереход к следующему после окончания, а также последовательный, случайный режимы и повтор одного элемента. На старых версиях хоста и при автономном входе сохраняется воспроизведение одного файла.

**Как загрузить внешние субтитры?**

Положите файл `.srt` или `.ass` с тем же именем рядом с видео (языковые суффиксы вроде `movie.ru.srt` допустимы), откройте видео из файлового менеджера и выберите субтитры в меню субтитров. По умолчанию субтитры выключены и сами никогда не включаются.

**Что записывает продолжение просмотра? Что-нибудь отправляется в сеть?**

Хранится только позиция последнего недосмотренного видео в виде дайджеста SHA-256 файла и значений времени, без имени файла и пути; открытие другого видео или завершение просмотра немедленно её удаляет. Все данные остаются на устройстве, ничего никуда не отправляется.

**Какие разрешения нужны плагину?**

Никаких разрешений на хранилище, камеру, микрофон и других чувствительных разрешений времени выполнения. Объявлены только разрешение на сеть для проверки обновлений (по запросу пользователя или не чаще раза в день) и защищённое подписью разрешение плагина для входа через файловый менеджер.

**Можно ли пользоваться плеером отдельно от AutoJs6?**

Да. Начиная с v2.0.0 у плагина есть вход с главного экрана: выберите видео через системный выбор файлов и смотрите, либо выберите этот плеер в меню `Открыть с помощью` другого приложения. Воспроизведение папки, поиск внешних субтитров и следование настройкам хоста по-прежнему требуют AutoJs6.

### Безопасность

******

Плагин построен по принципу запрета по умолчанию; все перечисленные ниже меры всегда включены, и отключить их нельзя:

- Ноль чувствительных разрешений: ни хранилища, ни других разрешений времени выполнения; сеть используется только для проверки выпусков на GitHub по запросу пользователя или раз в день.
- Никакой записи: воспроизведение, снимки кадров и извлечение миниатюр работают только на чтение от начала до конца; исходные видео никогда не изменяются, не перемещаются и не удаляются.
- Проверка входа по пунктам: вход через файловый менеджер защищён разрешением плагина уровня подписи, а у каждого запроса поштучно проверяются версия протокола, целевой URI, ClipData, метаданные, сборка хоста и разрешения только на чтение; любое несоответствие отклоняет запрос.
- Ограниченный доступ к соседним файлам: построение очереди и поиск субтитров идут через короткоживущую сессию под управлением хоста, которая может перечислять только прямых соседей выбранного файла; рекурсивные каталоги, запись и постоянные разрешения запрещены; внутренний плеер получает только проверенную ограниченную очередь и никогда не касается путей файловой системы.
- Изолированные независимые входы: обращённый к системе вход `ACTION_VIEW` принимает только запросы `video/*` с content URI только на чтение, отклоняет разрешения на запись, постоянные и префиксные разрешения и остаётся независимым от входа через файловый менеджер.
- Минимум данных для продолжения: история продолжения хранит только последнюю незавершённую запись в виде дайджеста SHA-256 и значений времени и очищается после завершения просмотра.
- Безопасная передача: `Открыть в другом приложении` заново собирает Intent только на чтение и исключает этот плагин из кандидатов, предотвращая расползание разрешений и зацикливание на себе.

### Интерфейс плагина (для разработчиков)

******

Хост обнаруживает и вызывает плагин по следующим идентификаторам:

```text
service action: org.autojs.plugin.EXPLORER_ACTION
execute action: org.autojs.plugin.EXPLORER_ACTION_EXECUTE
plugin id: three-amber-player
source namespace: io.github.supermonster003.autojs6.plugin.three.amber.player
stable application id: io.github.supermonster003.autojs6.plugin.three.amber.player
engine: explorer-action
variant: default
protocol version: v12
Explorer action id: play-video
Explorer placement: primary
access mode: read-only
Explorer MIME types: video/*
external view action: android.intent.action.VIEW
external MIME type: video/*
required host build: 5276
```

Реализация основана на explorer-action v12: регистрируются основное действие только для чтения `play-video` и действие панели выбора `play-video-selection`, принимаются типы `video/*` и сохраняются 23 расширения для старых хостов. Основное действие может ограниченно читать соседние файлы для очереди и субтитров; действие выбора сохраняет порядок 1-128 целей хоста и никогда не включает такое чтение. Совместимые сеансы могут передавать прогресс, а отсутствующие необязательные возможности безопасно отключаются. Аудио и изображения остаются отдельными плагинами.

Для полного взаимодействия с хостом нужны AutoJs6 6.8.0 (build 5276) или новее и Explorer Action v12; будущие обновления плагина не повысят это требование.

### Сборка

******


```powershell
.\gradlew.bat :app:assembleRelease
```

Параметры сборки берутся из `version.properties`; текущий минимальный SDK равен 24, целевой SDK равен 36.

### Структура ресурсов

******

```text
.readme/lang_*.json
.changelog/lang_*.json
.python/generate_markdown.py
app/src/main/assets/doc/CHANGELOG-*.md
app/src/main/res/values-*/strings.xml
app/src/main/res/raw-*/plugin_instruction.md
```

`strings.xml` локализует сведения о плагине и интерфейс плеера, а `plugin_instruction.md` содержит заметки по использованию, отображаемые на стороне хоста. Все файлы README и CHANGELOG генерируются из JSON-источников скриптом `.python/generate_markdown.py`: чтобы изменить документацию, отредактируйте `lang_*.json` в каталогах `.readme` и `.changelog` и заново запустите скрипт, не редактируя сгенерированные файлы Markdown.
