### Введение

******

3-Ember Player — это одновременно плагин файлового менеджера AutoJs6 и простой автономный видеоплеер. Он принимает временные URI content только для чтения, использует AndroidX Media3 ExoPlayer и никогда не изменяет исходное видео.

******

### Возможности

******

- Лёгкая совместимость XVID в MKV через встроенный декодер MPEG-4 Part 2 устройства с явным переходом к другому проигрывателю, если системный декодер недоступен или завершается ошибкой.
- Регистрирует основное действие Проводника только для чтения через версию 12 общего протокола `org.autojs.plugin.EXPLORER_ACTION` с необязательными ограниченными возможностями для соседних файлов и прогресса воспроизведения.
- Использует AndroidX Media3 ExoPlayer и PlayerView для автоматического воспроизведения, стандартных элементов управления, фокусировки звука, обработки перехода к noisy-аудиовыходу и интеграции с кодеками устройства.
- Восстанавливает позицию и намерение воспроизведения или паузы после повторного создания, а экран остается включенным только во время активного воспроизведения видео.
- Предоставляет отдельную экспортируемую точку входа `android.intent.action.VIEW` для content URI только для чтения с MIME-типом `video/*`.
- После ошибки воспроизведения предлагает безопасное действие Открыть в другом приложении, заново создавая Intent просмотра только для чтения и исключая этот плагин из списка кандидатов.
- Обеспечивает иммерсивное полноэкранное воспроизведение с жестами для яркости, громкости и перемотки, переходами по двойному касанию, временным ускорением по долгому нажатию и блокировкой управления.
- Предлагает скорости воспроизведения от 0,25× до 3×, а также переключение масштаба изображения и ориентации экрана одним касанием.
- История продолжения хранит ровно одно последнее незавершённое видео в виде SHA-256-дайджеста идентификатора и значений времени; открытие другого видео сразу удаляет запись, а завершённое воспроизведение никогда не сохраняется.
- Позволяет выбирать встроенные аудиодорожки и субтитры, по умолчанию отключает субтитры и четко отмечает неподдерживаемые дорожки.
- Предлагает повтор текущего видео, подробную панель метаданных, ориентацию по соотношению сторон и режим «картинка в картинке» на API 26+ с удаленным воспроизведением/паузой.
- Интегрирует MediaSession для управления с гарнитуры, Bluetooth и системы, а также мультимедийное уведомление с названием и прогрессом.
- Таймер сна на 15/30/45/60 минут или до конца видео, а также сохраняемые настройки чувствительности и шага двойного касания 5/10/30 секунд.
- Масштаб жестом от 0,25× до 4× со сбросом двойным касанием, целевое время и необязательные миниатюры в памяти при перемотке.
- Снимки текущего кадра без разрешений на Android 10+, сохраняемые отдельными PNG через MediaStore без изменения исходного видео.
- Естественно отсортированные очереди видео из той же папки через Explorer Action v12 с предыдущим / следующим, последовательным и случайным режимами, повтором одного элемента и автоматическим воспроизведением следующего.
- Обнаружение совпадающих внешних субтитров .srt и .ass, включая языковые суффиксы; по умолчанию они отключены и загружаются только после явного выбора.
- Создаёт контрастные светлые и тёмные семантические роли из одного цвета HCT, по умолчанию следует AutoJs6 и предлагает 19 локализованных цветов Material 500 и свой RGB с предпросмотром.
- Предоставляет автономный экран запуска и настройки языка, ночного режима и цвета с наследованием от хоста, продолжения одного видео, ручной и автоматической проверки обновлений, игнорируемых версий, истории выпусков и сведений о приложении и разработчике.

### Интеграция с хостом

******

Хост использует этот плагин для основного пути открытия видео и действия Воспроизвести.

После установки, включения, признания доверенным и проверки совместимости плагина открытие любого файла, распознанного хостом как видео, запускает действие `play-video` как основной просмотрщик Проводника.

Если плагин отсутствует, отключен, не авторизован, недоступен, несовместим или не запускается, совместимый хост показывает инструкции по восстановлению. Системный список приложений открывается только после явного выбора Открыть в другом приложении.

Этот плагин работает только с видеофайлами. Воспроизведение аудио и просмотр изображений остаются отдельными возможностями плагинов и не включены в этот APK.

******

### Поддерживаемые форматы

******

Основное действие Проводника принимает `video/*` для всех типов видео, распознанных хостом, и сохраняет следующие 23 точных фильтра расширений для совместимости со старыми хостами:

```text
MP4, MPEG4, MPG4, AVI, MKV, MOV, FLV, WEBM, M4V, 3GP, MPEG, 3G2, 3GP2, 3GPP, F4V, M2T, M2TS, MTS, TS, MPG, MPE, VOB, QT
```

### Интерфейс плагина

******

Хост обнаруживает и запускает плагин со следующими идентификаторами:

```text
service action: org.autojs.plugin.EXPLORER_ACTION
execute action: org.autojs.plugin.EXPLORER_ACTION_EXECUTE
plugin id: video-player
source namespace: io.github.supermonster003.autojs6.plugin.threeemberplayer
stable application id: io.github.supermonster003.autojs6.plugin.videoplayer
engine: explorer-action
variant: default
Explorer action id: play-video
Explorer placement: primary
access mode: read-only
Explorer MIME types: video/*
external view action: android.intent.action.VIEW
external MIME type: video/*
required host build: 5276
```

Версия 2.0 предоставляет основное действие Проводника только для чтения по протоколу v12. Совместимый хост может прикреплять к запросу возможности прямого доступа к соседним файлам и прогресса воспроизведения; хосты без этих необязательных расширений сохраняют воспроизведение одного файла. Независимая внешняя точка входа по-прежнему принимает только content URI для чтения с допустимым подтипом MIME `video/*`.

Для полной совместной работы требуются AutoJs6 6.8.0 build 5276 или новее и Explorer Action v12; будущие возможности плагина не повысят это требование.

### Безопасность

******

Приложение не запрашивает доступ к хранилищу и никогда не записывает исходные видео. Интернет используется только для запущенной пользователем или ежедневной проверки выпусков GitHub. Защищенная подписью граница Проводника проверяет полную оболочку протокола v12, ровно одну выбранную цель, связь с родителем, ClipData, метаданные, сборку хоста и доступ только для чтения. Необязательные Host Session привязываются хостом к UID плагина и разрешают только перечислять непосредственного родителя выбранного файла и открывать выбранный файл либо читаемый непосредственный соседний файл. Закрытый проигрыватель проверяет ограниченную непрозрачную очередь и никогда не получает путь файловой системы. Общедоступная граница ACTION_VIEW остается независимой и однофайловой.

******

### Ограничения безопасности

******

- Проводник начинает ровно с одного выбранного content URI; необязательная Host Session может раскрывать только читаемые непосредственные соседние файлы и никогда не дает рекурсивного доступа к папкам.
- Для запуска из Проводника требуется разрешение уровня signature `org.autojs.permission.PLUGIN`.
- Доступ на запись и постоянный доступ всегда отклоняются. Доступ prefix, используемый для проверки родительского URI Проводника, никогда не передается проигрывателю.
- Общедоступная граница ACTION_VIEW отклоняет доступ на запись, постоянный доступ и доступ prefix.
- Сначала определяются внешние кандидаты, затем список фильтруется до других пакетов, которые запускаются с новым Intent только для чтения.
- История продолжения хранит ровно одно последнее незавершённое видео в виде SHA-256-дайджеста идентификатора и значений времени; открытие другого видео сразу удаляет запись, а завершённое воспроизведение никогда не сохраняется.
- Распознавание как видео или наличие устаревшего расширения в списке не гарантирует декодирование на каждом устройстве. Фактическая поддержка воспроизведения определяется Media3 и установленными платформенными кодеками.
